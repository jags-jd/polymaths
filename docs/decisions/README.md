# Decisions (ADRs)

One file per architectural decision: `YYYY-MM-DD-short-name.md`.

Template:

```
# <Title>

**Date:** YYYY-MM-DD
**Status:** Accepted | Superseded by <file>

## Context
What problem or question forced a decision?

## Decision
What we chose, in one or two sentences, then the details.

## Consequences
What this makes easy, what it makes hard, what we must now always do.

## Alternatives considered
What else we looked at and why not.
```

Never edit an accepted ADR's decision. If it changes, write a new one and mark the old one superseded.
